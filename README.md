# Orbiluz

Tienda online de decoración que se enciende (Shopify). Aquí están la marca y todo el material de la tienda.

| Carpeta o archivo | Qué hay |
|---|---|
| `marca/` | **Logos** (`marca/logo/`: SVG y PNG en versiones luna, noche, blanco y negro; icono y avatar), fuentes (Unbounded y DM Sans) y hoja de marca |
| `fotos/` | Fotos de producto, escenas, banners de la web y los scripts que las generan (`fotos/scripts/`) |
| `anuncios/meta/` | Creatividades estáticas para Meta Ads (4:5 y 9:16), escenas base, textos y plan de test |
| `contenido/` | Sistema de contenido (hooks, ángulos, guiones), prototipos de vídeo y material reutilizable |
| `tema/` | Archivos del tema de Shopify (Horizon personalizado): secciones, plantillas, estilos y traducciones |
| `fichas/` | Descripciones de producto (HTML) |
| `politicas-para-pegar.html` | Políticas legales listas para copiar en Shopify |
| `estudio-mercado.md`, `productos-candidatos.md` | Estudio de mercado y selección de productos |
| `TRASPASO.md` | Estado actual de la tienda, IDs y tareas pendientes |

**Normas:**
- Nada de datos ni reseñas inventados.
- Nada de tokens en el repositorio.
- Español de España y diseño pensado para el móvil.
- Los anuncios no llevan precios.
